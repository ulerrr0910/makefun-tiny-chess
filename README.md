A 4,096-byte Python chess engine: alpha-beta search with iterative deepening, quiescence search, killer-move ordering, check extension, and piece-square tables (endgame king table included). It searches to a fixed node budget and plays deterministically, entering make.fun's tiny-chess-01 gauntlet over HTTP.

## Run it

```sh
python3 main.py   # needs MAKEFUN_ENV_URL; plays every game the env serves
```
